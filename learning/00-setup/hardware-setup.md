# 0 · 초기 셋팅 — ESP32와 압력센서를 방석에 붙이기

> Claude Code에서 **"0번 시작"**이라고 하면 이 순서대로 한 단계씩 안내한다 ([CLAUDE.md](../../CLAUDE.md) 0절).
> 단계마다 "완료"라고 하면 다음으로 넘어간다. 사진은 이 폴더에 `YYYY-MM-DD_hw-번호-이름.jpg`로 남긴다.

| 파트 | 언제 | 끝나면 |
|---|---|---|
| **A · 준비와 배선** | 부품이 도착하면 (9주 첫 수업 전후) | 보드가 PC와 연결되고, 센서 4개가 배선 표대로 꽂혀 있다 → **칸 ① 시작** |
| **B · 방석 부착** | 칸 ① 미니 프로젝트로 센서 4개 모두 숫자가 나오는 것을 확인한 뒤 | 방석에 고정된 센서 4개와 의자에 고정된 ESP32 |

센서값을 읽는 MicroPython 코드는 칸 ①에서 **내가 직접** 쓴다. 0번에서는 코드를 대신 써 주지 않는다.

---

## 안전 수칙 (먼저 읽기)

- 배선을 바꿀 때는 **USB를 뽑는다**.
- 센서 전원은 **3V3 핀만** 쓴다. 5V 핀에 연결하지 않는다.
- 센서는 **GPIO 4 · 5 · 6 · 7**에만 연결한다 (Wi-Fi를 켜면 GPIO 11~20은 아날로그로 못 씀). 0 · 3 · 45 · 46 · 43 · 44 · 48번은 쓰지 않는다.
- FSR402 꼬리(은색 단자 쪽)는 **납땜 · 열 금지**, 뿌리 부분을 접지 않는다.
- 3V3와 GND가 바로 닿지 않게 한다 (같은 줄에 꽂지 않기).

### A2. PC 도구와 보드 연결

1. 칸 ①과 조교 S1에서 안내하는 도구를 우선 쓴다. 미리 하려면 **Thonny**를 설치한다.
2. 보드를 USB로 연결하고, Thonny 인터프리터를 **MicroPython (ESP32)** 로 고른다.
3. 펌웨어가 없으면 Thonny의 "MicroPython 설치 또는 업데이트"에서 **ESP32-S3** 계열을 고른다. 보드가 안 잡히면 **BOOT 버튼을 누른 채로** USB를 꽂는다.
4. 셸(REPL)에 `>>>`가 뜨면 성공. 보드 이름 · 펌웨어 버전을 기록해 둔다.

### A3. Wi-Fi 확인

- ESP32는 **2.4GHz Wi-Fi만** 된다. 집 공유기가 5GHz만 쓰거나, 폰 핫스팟이 5GHz로 되어 있으면 2.4GHz로 바꾼다.
- 집 Wi-Fi와 폰 핫스팟(강의실 시연용) 이름을 둘 다 적어 둔다. 비밀번호는 문서나 사진에 남기지 않는다.

### A4. 센서 선 연결 (납땜 없이)

1. FSR402 끝의 금속 단자 2개를 **점퍼선 암 커넥터**에 하나씩 꽂는다.
2. 연결부를 테이프로 감아 빠지지 않게 한다. 센서마다 ①~④ 번호 스티커를 붙인다.

### A5. 브레드보드 배선 → 사진 `hw-2-wiring`

1. ESP32를 브레드보드 가운데 홈을 가로질러 꽂는다.
2. ESP32 `3V3` → 브레드보드 + 줄, `G`(GND) → − 줄.
3. 센서마다 아래처럼 연결한다 (센서 하나 = 저항 하나).

| 센서 | 센서 한쪽 다리 | 센서 다른 쪽 다리 → 같은 세로줄에 | 그 세로줄 → 10kΩ → |
|---|---|---|---|
| ① 왼 허벅지 | + 줄 (3V3) | ESP32 **GPIO 4** | − 줄 (GND) |
| ② 오른 허벅지 | + 줄 (3V3) | ESP32 **GPIO 5** | − 줄 (GND) |
| ③ 왼 엉덩이 | + 줄 (3V3) | ESP32 **GPIO 6** | − 줄 (GND) |
| ④ 오른 엉덩이 | + 줄 (3V3) | ESP32 **GPIO 7** | − 줄 (GND) |

4. 표와 실제 배선을 한 줄씩 다시 대조한다 (특히 3V3와 GND가 바뀌지 않았는지).
5. 여기서 **칸 ①을 시작**한다. 센서 하나씩 숫자가 나오는지는 ①의 미니 프로젝트에서 내가 쓴 코드로 확인한다.

### A6. 방석 위치 표시 → 사진 `hw-3-marks`

1. 방석을 의자에 올리고 **바른 자세로 깊이** 앉는다.
2. 엉덩이 아래 튀어나온 뼈(좌골) 두 곳을 손으로 찾아 방석에 표시 → ③ 왼 엉덩이 · ④ 오른 엉덩이 자리.
3. 양쪽 허벅지 가운데 아래를 표시 → ① 왼 허벅지 · ② 오른 허벅지 자리.
4. 표시가 앉은 사람 기준 좌우인지 확인한다 (① ③이 내 왼쪽).
5. 방석을 뒤집어 **아랫면의 같은 자리**에 다시 표시한다 (방석 가장자리에서 거리를 재서 옮긴다). 센서는 아랫면에 붙인다.
6. 택배 상자 골판지로 지름 5~6cm 원판 4개, 받침 4장을 자른다.

## 파트 B · 방석 부착 (칸 ① 확인 후)

### B1. 센서 샌드위치 → 사진 `hw-4-sandwich`

센서마다 방석 아랫면 쪽부터: **원판 → 센서(감지 면이 원판 쪽) → 받침**. 원판이 몸무게를 센서 쪽으로 모아 위치가 조금 어긋나도 값이 잡히고, 받침은 의자 좌판의 굴곡에서 센서를 평평하게 지켜 준다.

### B2. 방석에 고정 → 사진 `hw-5-mounted`

1. 방석 **아랫면**의 표시한 자리에 샌드위치를 대고, 받침 가장자리를 테이프로 방석에 붙인다. 감지 면 한가운데는 테이프로 덮지 않는다.
2. 센서 꼬리와 연결부는 **방석 가장자리로** 빼서 테이프로 감아 둔다 — 앉았을 때 몸 아래에 오지 않게.
3. 따로 덮개는 필요 없다 (방석이 덮개). 센서 면이 아래로 가게 방석을 의자에 올리고, 끈이 있으면 의자에 묶는다 (실물에 고정돼 있어야 한다 — 손에 들면 최종 1-B 0점).

### B3. 보드 · 배터리 고정 → 사진 `hw-6-board`

1. 브레드보드 + ESP32 + 보조배터리를 의자 좌판 아래나 옆에 벨크로 · 케이블타이로 고정한다.
2. 점퍼선이 바퀴나 의자 회전에 걸리지 않게 묶어 정리한다.

### B4. 최종 점검 (30초) → 사진 `hw-7-final`

1. 칸 ①에서 만든 코드로 숫자를 띄운다.
2. 손으로 ① → ② → ③ → ④ 순서로 하나씩 눌러, 해당 숫자만 오르는지 확인한다.
3. 바른 자세로 앉아 네 값이 모두 0이 아닌지 확인한다. 하나가 계속 0이면 그 센서의 배선 · 연결부를 다시 본다.
4. 이 30초 점검은 발표 · 시연 전에 매번 한다.
